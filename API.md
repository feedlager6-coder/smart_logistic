# SmartRoute — Справочник API

> Все API-методы, которые предоставляет сервер. Написано простым языком.

Базовый URL: `/api`
Сервер работает на порту **8080** (в разработке).

---

## Проверка работоспособности

### GET /api/healthz
Просто проверяет, что сервер запущен и отвечает.

**Ответ:**
```json
{ "status": "ok" }
```

---

## Магазины

### GET /api/stores
Возвращает список всех магазинов из базы данных.

**Ответ:** массив магазинов
```json
[
  {
    "id": 1,
    "name": "Пятёрочка Центр",
    "address": "Москва, ул. Ленина, 5",
    "lat": 55.7558,
    "lon": 37.6173,
    "geocode_status": "found",
    "time_window_from": "09:00",
    "time_window_to": "18:00",
    "unload_minutes": 15,
    "created_at": "2026-05-27 10:00:00"
  }
]
```

Поле `geocode_status`:
- `found` — координаты найдены, магазин можно включить в маршрут
- `not_found` — адрес не распознан, нужно исправить
- `pending` — ещё не геокодировали

---

### POST /api/stores
Добавляет новый магазин. Сервер сам геокодирует адрес (находит координаты).

**Тело запроса:**
```json
{
  "name": "Магазин Магнит",
  "address": "Москва, ул. Гагарина, 12",
  "time_window_from": "09:00",
  "time_window_to": "18:00",
  "unload_minutes": 15
}
```

**Ответ:** созданный магазин (такой же формат, как в GET /api/stores)

---

### GET /api/stores/{id}
Возвращает один магазин по его номеру.

**Пример:** `GET /api/stores/5`

**Ответ:** объект магазина или ошибка 404, если не найден.

---

### PUT /api/stores/{id}
Обновляет данные магазина. Можно передать только те поля, которые нужно изменить.

**Пример:** `PUT /api/stores/5`

**Тело запроса (все поля необязательны):**
```json
{
  "name": "Новое название",
  "address": "Новый адрес",
  "time_window_from": "10:00",
  "time_window_to": "19:00",
  "unload_minutes": 20
}
```

Если изменился адрес — сервер автоматически пересчитывает координаты.

---

### DELETE /api/stores/{id}
Удаляет магазин из базы.

**Пример:** `DELETE /api/stores/5`

**Ответ:** пустой (код 204)

---

### POST /api/stores/{id}/geocode
Запрашивает координаты для магазина заново. Полезно, если при добавлении геокодирование не сработало.

**Пример:** `POST /api/stores/5/geocode`

**Ответ:** обновлённый объект магазина с новыми координатами.

---

### GET /api/stores/template
Скачивает пустой Excel-шаблон для заполнения магазинов.

**Ответ:** файл `.xlsx` (скачивается как `smartroute_template.xlsx`)

Структура шаблона:
| Название | Адрес | Время с | Время до | Время разгрузки мин |
|---|---|---|---|---|
| Магазин Пятёрочка | ул. Ленина 5 | 09:00 | 18:00 | 15 |

---

### POST /api/stores/import
Загружает магазины из Excel-файла. Сервер читает каждую строку, геокодирует адреса и сохраняет в базу.

**Тело запроса:** файл Excel (`multipart/form-data`, поле `file`)

**Ответ:**
```json
{
  "total": 10,
  "imported": 8,
  "failed": 2,
  "stores": [ ...список добавленных магазинов... ]
}
```

Внимание: импорт может быть медленным, так как между геокодированием каждого адреса делается пауза 1.1 секунды (ограничение бесплатного Nominatim API).

## Маршруты

### POST /api/route/build
Главный метод. Запускает алгоритм оптимизации и возвращает готовые маршруты.

**Тело запроса:**
```json
{
  "store_ids": [1, 2, 3, 4, 5],
  "vehicles": [
    { "name": "Газель 1", "capacity_kg": 1500 },
    { "name": "Газель 2", "capacity_kg": 1500 }
  ],
  "depot_lat": 55.7558,
  "depot_lon": 37.6173,
  "use_time_windows": true,
  "use_unload_time": true
}
```

| Поле | Обязательное | Описание |
|---|---|---|
| `store_ids` | Да | Список ID магазинов для включения в маршрут |
| `vehicles` | Да | Список машин с именами и (опционально) грузоподъёмностью |
| `depot_lat`, `depot_lon` | Нет | Координаты склада (по умолчанию центр Москвы) |
| `use_time_windows` | Нет | Учитывать временные окна магазинов |
| `use_unload_time` | Нет | Учитывать время разгрузки |

**Ответ:**
```json
{
  "routes": [
    {
      "vehicle_name": "Газель 1",
      "stores": [
        {
          "order": 1,
          "store_id": 3,
          "store_name": "Пятёрочка Центр",
          "address": "Москва, ул. Ленина, 5",
          "lat": 55.7558,
          "lon": 37.6173,
          "arrive_by": "18:00"
        }
      ],
      "total_km": 42.5,
      "estimated_minutes": 85,
      "yandex_url": "https://yandex.ru/maps/?rtext=...",
      "whatsapp_url": "https://wa.me/?text=..."
    }
  ],
  "savings": {
    "optimized_km": 85.0,
    "unoptimized_km": 110.5,
    "saved_km": 25.5,
    "saved_rub_day": 306,
    "saved_rub_month": 9180
  },
  "total_km": 85.0
}
```

## Аналитика

### GET /api/analytics/summary
Общая статистика за всё время.

**Ответ:**
```json
{
  "total_routes": 47,
  "total_km": 3850.5,
  "saved_km": 885.6,
  "saved_rub": 10627,
  "avg_points_per_route": 8.3
}
```

---

### GET /api/analytics/daily
Статистика по дням за последние 30 дней.

**Ответ:** массив записей
```json
[
  {
    "date": "2026-05-01",
    "routes": 3,
    "total_km": 245.0,
    "saved_km": 56.3,
    "saved_rub": 675
  }
]
```

---

### GET /api/analytics/monthly
Статистика по месяцам за последние 12 месяцев.

**Ответ:** массив записей
```json
[
  {
    "month": "2026-04",
    "routes": 62,
    "total_km": 5200.0,
    "saved_rub": 14352
  }
]
```

---

### GET /api/analytics/top-stores
Топ-10 магазинов по количеству визитов.

**Ответ:** массив магазинов
```json
[
  {
    "store_id": 1,
    "store_name": "Пятёрочка Центр",
    "visit_count": 28
  }
]
```

## Коды ошибок

| Код | Что означает |
|---|---|
| 200 | Успешно |
| 201 | Создан (при добавлении магазина) |
| 204 | Удалён (при удалении магазина) |
| 400 | Неверный запрос (например, не выбраны магазины или машины) |
| 404 | Не найдено (магазин с таким ID не существует) |
| 500 | Ошибка сервера |
