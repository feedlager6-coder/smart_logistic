## 3. Риски, которые остались

### Средние риски

| Риск | Описание | Митигация |
|---|---|---|
| Геокодинг Nominatim | Бесплатный fallback — медленный (1 req/sec) и иногда неточный для МСК/регионов | Установить YANDEX_GEOCODER_API_KEY |
| OSRM публичный | router.project-osrm.org — публичный сервер без гарантий uptime | Есть fallback на Haversine; при живой демонстрации может упасть |
| Rate limiting по IP | Хранится в памяти (dict), сбрасывается при рестарте | Для демо — не критично |

### Низкие риски

| Риск | Описание |
|---|---|
| Connection pool | Нет пула подключений к PostgreSQL — при нагрузке >50 concurrent запросов риск "too many connections". Для MVP/демо не критично. |
| import_jobs без TTL | Dict растёт в памяти без очистки. При 1000+ импортов. Для демо не критично. |
| На телефоне Яндекс.Навигатор лимит 20 точек | Если маршрут >20 точек — несколько ссылок. Система предупреждает, но клиент может не ожидать. |

### Не реализовано (за рамками MVP)

- Email-подтверждение при регистрации
- Уведомления (email/telegram) диспетчеру
- Мобильное приложение для водителей
- Интеграция с 1С напрямую (только через Excel)

## 4. Готовность к демонстрации

**Итоговая оценка: 8.5/10**

### Сильные стороны продукта (показывать клиенту)
1. **Скорость**: 100 точек → маршрут за 20–30 сек (измеримо, показывается в реальном времени)
2. **Яндекс Навигатор**: открывается одним кликом — водители понимают сразу
3. **Импорт Excel**: работает с любым форматом через маппинг колонок
4. **Цифры экономии**: км и ₽ в реальном времени — это то, что принимает решение
5. **История + аналитика**: показывает накопленный эффект за период
6. **Карта с маршрутами**: визуально впечатляет, цветные маршруты для каждой машины

### Что нужно сделать перед встречей
- [ ] Загрузить реальные магазины клиента (или максимально реалистичные тестовые данные)
- [ ] Убедиться что YANDEX_GEOCODER_API_KEY установлен
- [ ] Проверить геокодинг всей базы (>85% "найдено")
- [ ] Построить маршрут заранее — знать ожидаемые цифры экономии
- [ ] Иметь скриншот карты как запасной вариант
