# Чеклист подготовки перед встречей с клиентом

---

## За 1 день до встречи

### Данные клиента
- [ ] Узнать количество машин в парке
- [ ] Узнать примерный ежедневный пробег
- [ ] Попросить тестовую выгрузку магазинов (Excel/CSV) — хотя бы 20–30 точек
- [ ] Если не дали данные — подготовить тестовый файл с реалистичными адресами по городу клиента

### Подготовка системы
- [ ] Загрузить данные клиента (или тестовые) в систему
- [ ] Проверить что геокодирование прошло успешно (>85% "найдено")
- [ ] Вручную исправить 2–3 проблемных адреса (это хорошо показывает гибкость системы)
- [ ] Создать тестовый автопарк: 3–5 машин с именами "Газель 1", "Газель 2" и т.д.
- [ ] Построить маршрут заранее — знать ожидаемые цифры экономии

### Контент для встречи
- [ ] Знать цифры экономии для их парка (формула: km × cost_per_km × 0.2)
- [ ] Подготовить скриншот карты с результатом (на случай проблем с интернетом)
- [ ] Распечатать 1 страницу маршрутного листа (показывает "бумажную" функцию)

---

## За 1 час до встречи

- [ ] Открыть SmartRoute в браузере, войти в систему
- [ ] Проверить что все магазины загружены и видны
- [ ] Убедиться что интернет работает стабильно
- [ ] Закрыть все лишние вкладки и программы
- [ ] Проверить что звук/микрофон работает (если онлайн)

---

## Структура встречи (напоминание)

| Время | Блок |
|---|---|
| 0–2 мин | Приветствие, вопрос о текущем процессе |
| 2–4 мин | База магазинов — импорт, геокодинг |
| 4–8 мин | Построение маршрута (живой расчёт) |
| 8–11 мин | Результат: карта, экономия, Яндекс.Навигатор |
| 11–13 мин | История, аналитика |
| 13–15 мин | Вопросы, следующий шаг |

| Параметр | Значение клиента |
|---|---|
| Количество машин | ___ |
| Точек в день на машину | ___ |
| Пробег в день (оценка) | ___ км |
| Текущий способ планирования | ___ |
| Время диспетчера на маршруты | ___ мин/день |

---

## После встречи

- [ ] Отправить итоговое письмо/сообщение в течение 2 часов
- [ ] Вложить коммерческое предложение с цифрами конкретно для их парка
- [ ] Зафиксировать договорённость о следующем шаге
- [ ] Если согласились на пилот — запросить реальную базу магазинов

---

## Красные флаги (когда остановиться)

- Клиент не имеет полномочий принять решение → попросить организовать встречу с ЛПР
- Конкурент уже глубоко интегрирован (1–2 года использования) → переключиться на боль с аналитикой
- Меньше 3 машин в парке → ROI низкий, предложить бесплатный тариф или отложить
