ИНСТРУКЦИЯ ПО УСТАНОВКЕ И ЗАПУСКУ:

1. УСТАНОВКА:
   Запустите файл:
   👉 SmartRoute_1C_Agent_Setup.exe

   Программа автоматически:
   - Установит агент в систему
   - Создаст ярлык «SmartRoute 1C Agent» на Рабочем столе
   - Запустит окно настройки

   Если установщик недоступен, скачайте ZIP-архив из того же раздела,
   распакуйте его и запустите SmartRoute_Agent.exe. Python не требуется.

2. НАСТРОЙКА (3 простых шага в окне программы):
   - Вкладка «Шаг 1: Привязка»: Введите код привязки (SMARTROUTE-XXXX-YYYY) из личного кабинета
     SmartRoute и нажмите «Привязать к SmartRoute».
   - Вкладка «Шаг 2: База 1С»: Выберите вашу базу 1С из выпадающего списка (или укажите строку подключения),
     введите логин и пароль пользователя 1С и нажмите «Проверить и сохранить подключение 1С».
   - Вкладка «Шаг 3: Синхронизация»: Нажмите «Синхронизировать сейчас». Агент начнет обмен данными
     и будет автоматически передавать заказы и статусы каждые 5 минут.

--------------------------------------------------------------------------------
ТРЕБОВАНИЯ:
- ОС: Windows 7 / 8.1 / 10 / 11 / Windows Server 2012+ (64-bit)
- 1С:Предприятие 8.3 / 8.2 (Управление торговлей, ERP, Комплексная автоматизация, УНФ)
- Python или дополнительные библиотеки НЕ требуются.

ВАЖНО:
- Для двусторонней синхронизации нужен компьютер с Windows и доступной базой 1С.
- Если 1С работает на Linux-сервере, используйте ручную интеграцию через BSL + API
  в веб-интерфейсе SmartRoute.
- Не отправляйте в поддержку пароль 1С, токен агента или файл config.json.
