================================================================================
          SmartRoute 1C Agent (Windows 64-bit Native) — Версия 3.2.0
================================================================================

ИНСТРУКЦИЯ ПО УСТАНОВКЕ И ЗАПУСКУ:

1. УСТАНОВКА:
   Запустите файл:
   👉 SmartRoute_1C_Agent_Setup.exe

   Программа автоматически:
   - Установит агент в систему
   - Создаст ярлык «SmartRoute 1C Agent» на Рабочем столе
   - Запустит окно настройки

    Если установщик заблокирован политикой Windows, скачайте ZIP-архив из того же раздела,
    распакуйте его и запустите Установка_SmartRoute.bat. Скрипт создаст ярлык и откроет
    HTA-версию агента. Python не требуется.

2. НАСТРОЙКА (3 простых шага в окне программы):
   - Вкладка «Шаг 1: Привязка»: Сначала вставьте адрес опубликованного сервера SmartRoute
     (его показывает веб-кабинет в разделе «Интеграции»), затем введите код привязки
     (SMARTROUTE-XXXX-YYYY) и нажмите «Привязать к SmartRoute». Не используйте адрес
     dev-preview, старый Google Run или страницу сайта «under construction».
   - Вкладка «Шаг 2: База 1С»: Выберите вашу базу 1С из выпадающего списка (или укажите строку подключения),
     введите логин и пароль пользователя 1С и нажмите «Проверить и сохранить подключение 1С».
   - Вкладка «Шаг 3: Синхронизация»: Нажмите «Проверить связь с сервером». Агент подтвердит
     доступность SmartRoute и будет отправлять heartbeat каждые 5 минут. Полный обмен заказами
     и статусами выполняется отдельным модулем 1С/BSL.

--------------------------------------------------------------------------------
ТРЕБОВАНИЯ:
- ОС: Windows 7 / 8.1 / 10 / 11 / Windows Server 2012+ (64-bit)
- 1С:Предприятие 8.3 / 8.2 (Управление торговлей, ERP, Комплексная автоматизация, УНФ)
- Python или дополнительные библиотеки НЕ требуются.

ВАЖНО:
- Для полного двустороннего обмена нужен компьютер с Windows, доступная база 1С и отдельный
  модуль обмена 1С/BSL.
- Если 1С работает на Linux-сервере, используйте ручную интеграцию через BSL + API
  в веб-интерфейсе SmartRoute.
- Не отправляйте в поддержку пароль 1С, токен агента или файл config.json.
