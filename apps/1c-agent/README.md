# SmartRoute 1C Windows Agent

Официальный агент двусторонней интеграции между **1С:Предприятие 8.3/8.2** и логистической платформой **SmartRoute**.

## Возможности
- ⚡️ **Быстрая привязка** по коду из личного кабинета SmartRoute.
- 🔍 **Автоматическое обнаружение баз 1С** из системных файлов `ibases.v8i`.
- 🔌 **Поддержка любых конфигураций** (УТ 10.3/11, КА 1.1/2, ERP, Розница, УНФ, БП 3.0, самописные) через COMConnector и HTTP REST.
- 📦 **Автоматическая синхронизация заказов** в SmartRoute с сохранением номенклатуры, веса, объема, временных окон и телефонов клиентов.
- 🚚 **Обратная запись статусов доставки** («В пути», «Доставлено», «Отказ»), номера маршрута, времени доставки и фотоподтверждений (POD) в документы 1С.
- 🛡️ **Надежность и отказоустойчивость**: повторные попытки (exponential backoff), локальное шифрование, подробное логирование.

## Быстрый запуск
1. Для клиента скачайте `SmartRoute_1C_Agent_Setup.exe` из раздела «Интеграции» и запустите установщик.
2. Для portable-запуска используйте `SmartRoute_Agent.exe` из ZIP-архива.
3. Для разработки GUI запускайте `python smartroute_agent_gui.py`; для фонового режима: `python smartroute_agent_cli.py --daemon`.
4. Подробная инструкция для клиента: см. [CLIENT_GUIDE.md](CLIENT_GUIDE.md).
5. Техническая архитектура и сборка Windows-артефактов: см. [DEVELOPER_GUIDE.md](DEVELOPER_GUIDE.md).
