2. dist_cb работает через dist_matrix:

int_matrix = [[int(v) for v in row] for row in dist_matrix]

def dist_cb(from_idx, to_idx):
return int_matrix[manager.IndexToNode(from_idx)][manager.IndexToNode(to_idx)]

3. GraphHopper Matrix API возвращает:

(distance_matrix, time_matrix)

travel_min = int(
int_matrix[from_node][to_node] /
max(speed_m_per_min, 1)
