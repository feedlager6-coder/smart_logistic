SmartRoute — Полное проектирование интеграции с 1С (без написания кода “наугад”)

Контекст

Ты работаешь над коммерческим продуктом SmartRoute.

В репозитории уже есть первая версия раздела “Интеграции”.

Там есть подключение 1С.

Была предпринята попытка сделать интеграцию через BSL-файл.

После исследования стало понятно, что это плохой UX.

Также стало понятно, что Python не умеет генерировать настоящий EPF-файл.

Поэтому дальнейшая архитектура будет следующей:

SmartRoute распространяет ГОТОВЫЙ EPF-файл.

EPF собирается один раз в настоящем Конфигураторе 1С.

После этого SmartRoute только раздает этот файл клиентам.

BSL больше не является пользовательским артефактом.

Его пользователь никогда не должен видеть.

⸻
