Задачи

Спроектируй универсальную архитектуру интеграционного слоя SmartRoute.

Она должна позволять в будущем легко подключать:

Excel
CSV
Google Sheets
1С
МойСклад
Bitrix24
amoCRM
другие CRM через API

При этом ядро SmartRoute (маршрутизация, импорт, геокодирование и построение маршрутов) не должно зависеть от конкретной CRM.

⸻

Спроектируй систему API Keys.

Опиши:

структуру хранения API-ключей;
модель безопасности;
права доступа (scopes);
ротацию ключей;
возможность отключения ключей;
логирование использования.

Пока ничего не реализовывай.

⸻

Спроектируй публичный REST API SmartRoute.

Опиши рекомендуемые эндпоинты.

Например:

создание заявок;
обновление заявок;
получение списка заявок;
удаление;
построение маршрута;
получение результатов;
получение списка магазинов;
управление пользователями (если потребуется).

Важно, чтобы API выглядел профессионально и мог использоваться сторонними разработчиками.

Исследуй возможность подключения Google Sheets.

Нужно определить:

можно ли подключать таблицу по ссылке;
как происходит авторизация;

как лучше реализовать синхронизацию.

Пока без реализации.
