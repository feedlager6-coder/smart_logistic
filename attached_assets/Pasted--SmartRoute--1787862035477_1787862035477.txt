Проблема: при нажатии на кнопку «Скачать агент» на странице интеграции SmartRoute возвращается ошибка 404 (файл не найден).

Твоя задача — **найти и исправить причину 404 ошибки**, чтобы клиент мог успешно скачать Windows-установщик `SmartRoute_1C_Agent_Setup.exe`.

***

## 1. Диагностика

### 1.1. Проверь эндпоинт скачивания

1) Найди в коде бэкенда эндпоинт `/api/integrations/1c/agent/download` (или похожий).  
2) Проверь:
   - Существует ли этот эндпоинт физически (роут, контроллер, обработчик)?  
   - Какой путь к файлу он использует (например, `apps/1c-agent/builds/SmartRoute_1C_Agent_Setup.exe`)?  
   - Существует ли файл по этому пути?

3) Проверь логи бэкенда:
   - Есть ли запросы к этому эндпоинту?  
   - Что возвращает сервер (404, 500, 200)?

### 1.2. Проверь наличие файла установщика

1) Найди папку с агентом (например, `apps/1c-agent/`).  
2) Проверь, есть ли там:
   - Готовый `.exe` файл (например, `SmartRoute_1C_Agent_Setup.exe`).  
   - Или скрипты для сборки (PyInstaller `.spec`, Inno Setup `.iss`).

3) Если `.exe` нет:
   - Почему он не был собран?  
   - Есть ли инструкция по сборке?

***

## 2. Исправление

### 2.1. Если файл установщика существует

1) Проверь путь к файлу в эндпоинте:
   - Правильный ли путь (относительный или абсолютный)?  
   - Не опечатка ли в названии файла?

2) Исправь путь, если нужно:
   ```python
   # Пример (FastAPI)
   @app.get("/api/integrations/1c/agent/download")
   async def download_agent():
       file_path = "apps/1c-agent/builds/SmartRoute_1C_Agent_Setup.exe"
       return FileResponse(file_path, filename="SmartRoute_1C_Agent_Setup.exe", media_type="application/octet-stream")
   ```

3) Проверь права доступа:
   - Может ли сервер читать этот файл?  
   - Не заблокирован ли он (gitignore, permissions)?

### 2.2. Если файла установщика нет

1) **Собери установщик:**
   - Если есть PyInstaller-конфиг (`.spec`):
     ```bash
     pyinstaller --onefile --windowed --name "SmartRoute Agent" smartroute_agent_gui.py
     ```
   - Если есть Inno Setup-скрипт (`.iss`):
     ```bash
     iscc SmartRoute_1C_Agent_Setup.iss
     ```

2) **Положи готовый `.exe` в правильное место:**
   - Например, `apps/1c-agent/builds/SmartRoute_1C_Agent_Setup.exe`.  
   - Или `public/downloads/SmartRoute_1C_Agent_Setup.exe`.

3) **Если не можешь собрать на Linux:**
   - Явно укажи в документации, что `.exe` нужно собирать на Windows.  
   - Дай инструкцию по сборке.  
   - Временно положи `.zip` с исходниками агента и инструкцией.

### 2.3. Временное решение (если `.exe` нельзя собрать)

1) **Скачай исходники агента:**
   - Упакуй папку `apps/1c-agent/` в `.zip`.  
   - Положи в public папку (например, `public/downloads/smartroute_agent_source.zip`).

2) **Измени эндпоинт:**
   ```python
   @app.get("/api/integrations/1c/agent/download")
   async def download_agent():
       file_path = "public/downloads/smartroute_agent_source.zip"
       return FileResponse(file_path, filename="smartroute_agent_source.zip", media_type="application/zip")
   ```

3) **Обнови инструкцию для клиента:**
   - «Скачайте исходники агента.  
   - Установите Python 3.10+.  
   - Запустите `setup.bat` или следуйте инструкции в README.md.»

***

## 3. Тестирование

1) **Скачай файл через браузер:**
   - Открой SmartRoute в браузере.  
   - Перейди на вкладку «Интеграция с 1С» → «Приложение-агент».  
   - Нажми «Скачать агент».  
   - Проверь, что файл скачивается (не 404).

2) **Проверь содержимое файла:**
   - Если `.exe` — запусти, проверь, что это установщик.  
   - Если `.zip` — распакуй, проверь, что внутри все файлы.

3) **Проверь логи бэкенда:**
   - Есть ли запросы к эндпоинту?  
   - Возвращается ли 200?

***

## 4. Документация

Обнови инструкцию для клиента:

1) **Если `.exe` работает:**
   - «Нажмите “Скачать агент” → сохраните `SmartRoute_1C_Agent_Setup.exe`.  
   - Запустите установщик → нажмите “Далее” → “Установить”.»

2) **Если только исходники:**
   - «Нажмите “Скачать агент” → сохраните `smartroute_agent_source.zip`.  
   - Распакуйте архив.  
   - Установите Python 3.10+ (если не установлен).  
   - Запустите `setup.bat` или следуйте инструкции в README.md.»

## 5. Результат

Предоставь:

1) **Исправленный эндпоинт** (код, путь к файлу).  
2) **Рабочий файл для скачивания** (`.exe` или `.zip`).  
3) **Подтверждение тестирования** (скриншот скачивания, логи).  
4) **Обновлённую инструкцию для клиента**.
