ПРОБЛЕМА №1
МАССОВОЕ ДОБАВЛЕНИЕ НЕСОПОСТАВЛЕННЫХ МАГАЗИНОВ
==============================================

Сейчас после импорта заявок система показывает:

"92 точки не найдены в базе магазинов"

Есть возможность добавить их только по одной.

Это неудобно.

Нужно реализовать:

1. Кнопку:

"Добавить все несопоставленные магазины"

2. При нажатии система должна:

* пройтись по всем несопоставленным строкам;
* создать магазины автоматически;
* заполнить максимально возможное количество данных из файла заявок.

Использовать данные из импортируемого Excel:

* название;
* адрес;
* ссылка Яндекс (если есть);
* город;
* время с;
* время до;
* разгрузка минут;
* любые другие поля, которые уже есть в файле и которые могут быть полезны магазину.

Цель:

если информация уже присутствует в заявке, пользователь не должен вводить её второй раз вручную.

ПРОБЛЕМА №4
АВТОВЫБОР МАГАЗИНОВ ПОСЛЕ ИМПОРТА
=================================

Баг до сих пор воспроизводится.

Сценарий:

1. Есть существующие магазины.
2. Импортируются заявки.
3. Заявки корректно сопоставляются.
4. Нажимается кнопка "К маршруту".

Ожидаемое поведение:

Все сопоставленные магазины автоматически отмечаются на странице маршрута.

Фактическое поведение:

Иногда магазины не выбираются.

Нужно:

* найти причину;
* исправить;
* доказать исправление тестами.

Показать конкретный сценарий проверки.
