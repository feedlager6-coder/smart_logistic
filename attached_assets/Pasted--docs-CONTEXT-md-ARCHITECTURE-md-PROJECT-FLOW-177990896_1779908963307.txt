ЭТАП 2 — ИСПРАВЬ БАГИ

БАГ 1: 404 при POST /api/stores

Проверь в main.py:
1. Endpoint "/api/stores" существует
2. Pydantic модель StoreInput валидна
3. Нет конфликта с другими routes

Если endpoint есть но возвращает 404 —
проблема скорее всего в Vite proxy.
Проверь vite.config.ts:

server: {
  proxy: {
    '/api': {
      target: 'http://localhost:8080',
      changeOrigin: true,
      rewrite: (path) => path
    }
  }
}

Убедись что target указывает на правильный порт
где запущен FastAPI (8080 по README).

БАГ 2: 404 при GET /api/stores/template

Проверь порядок регистрации endpoints в main.py.
/template ОБЯЗАТЕЛЬНО должен быть ДО /{id}:

@app.get("/api/stores/template")  # ← ПЕРВЫМ
async def download_template(): ...

@app.get("/api/stores/{store_id}")  # ← ВТОРЫМ
async def get_store(store_id: int): ...

Если порядок неправильный — переставь.

Также проверь что endpoint возвращает
правильный Content-Type:
return StreamingResponse(
    stream,
    media_type="application/vnd.openxmlformats-officedocument.spreadsheetml.sheet",
    headers={"Content-Disposition": "attachment; filename=smartroute_template.xlsx"}
)

БАГ 3: Сайт ломается при нескольких курьерах

В solve_vrp() найди и исправь:

1. Убедись что vehicles передаётся как список словарей:
   vehicles = [
       {"name": "Газель 1", "capacity_kg": 1500},
       {"name": "Газель 2", "capacity_kg": 1500}
   ]

2. num_vehicles = len(vehicles) — не хардкод

3. Если capacities указаны — передавай как список int:
   capacities = [v.get("capacity_kg", 99999) for v in vehicles]

4. В OR-Tools убедись что depot index = 0:
   manager = pywrapcp.RoutingIndexManager(n, num_vehicles, 0)

5. Добавь обработку ошибок:
   try:
       solution = routing.SolveWithParameters(params)
       if not solution:
           # Вернуть простое распределение без OR-Tools
           return fallback_distribution(all_coords, num_vehicles)
   except Exception as e:
       logger.error(f"VRP error: {e}", exc_info=True)
       raise HTTPException(500, f"Ошибка оптимизации: {e}")

6. Функция fallback_distribution для случая когда
   OR-Tools не находит решение:
   
   def fallback_distribution(all_coords, num_vehicles):
       points = list(range(1, len(all_coords)))
       routes = [[] for _ in range(num_vehicles)]
       for i, point in enumerate(points):
           routes[i % num_vehicles].append(point)
       return routes
