Исправить только описанные ниже проблемы и провести полное тестирование до и после изменений.

ПРОБЛЕМА №1
ПОВТОРНЫЙ ИМПОРТ СОЗДАЁТ ДУБЛИКАТЫ

Сценарий:

В системе уже есть магазины.
Пользователь делает экспорт магазинов.
Пользователь импортирует этот же файл обратно.
Система создаёт новые магазины вместо того, чтобы распознать существующие.

Фактическое поведение:

Сейчас работает только дедупликация внутри самого файла.

Не работает дедупликация:

База данных ↔️ Новый импорт.

Это приводит к загрязнению базы клиента.

Что нужно реализовать:

Перед импортом выполнять поиск совпадений среди уже существующих магазинов текущего пользователя.

Проверять:

название магазина;
адрес;
нормализованный адрес;
координаты (если есть);
близость координат.

Система должна определить:

новые магазины;
существующие магазины;
потенциальные дубликаты.

После анализа показать понятный интерфейс.

Например:

Найдено:

8 новых магазинов
8 уже существующих

Что сделать?

(по умолчанию)

✔️ Импортировать только новые

Дополнительно:

○ Обновить существующие магазины
○ Импортировать всё как отдельные точки

Требования:

повторный импорт собственного экспортированного файла не должен создавать новые магазины по умолчанию;
пользователь должен понимать, что уже существует в системе;
протестировать экспорт → повторный импорт;
протестировать импорт файла с частично новыми магазинами;
протестировать импорт файла с полностью существующими магазинами.

⸻

ПРОБЛЕМА №2
ИСТОРИЯ МАРШРУТОВ

Сценарий:

Открыть историю маршрутов.
Нажать «Открыть маршрут».

Текущее поведение:

Появляется пустая белая страница.

Это критическая ошибка.

Нужно:

Найти причину.
Исправить.
Проверить:

маршрут из истории открывается корректно;
отображается карта;
отображаются маршруты;
отображаются автомобили;
отображаются точки;
отображается аналитика;
работают кнопки навигации;
работают действия на странице маршрута.

Проверить минимум:

последний маршрут;
несколько старых маршрутов;
маршрут с несколькими машинами.
