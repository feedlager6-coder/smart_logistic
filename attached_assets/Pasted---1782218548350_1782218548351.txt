ПРОЧИТАЙ ПОЛНОСТЬЮ.

Это не новая разработка с нуля.

Проект уже находится на стадии активного пользовательского тестирования.

В проекте уже реализованы:

* магазины;
* заявки на день;
* импорт Excel;
* маршруты;
* распределение по весу;
* предупреждения о перегрузе;
* автосопоставление магазинов;
* массовое добавление магазинов из заявок;
* автовыбор магазинов при переходе "К маршруту".

Перед началом работы:

1. Изучи:

   * replit.md
   * DEVELOPER_ONBOARDING.md
   * текущую реализацию orders/day orders
   * stores
   * routes

2. Проведи собственный аудит.

3. Сравни результаты аудита с проблемами ниже.

4. Сначала покажи план исправлений.

5. Только после этого приступай к реализации.

Для каждого изменения:

* объясни причину бага;
* покажи место возникновения;
* покажи что изменил;
* покажи тест;
* покажи результат.

КОНТЕКСТ ПРОЕКТА
================

Основной пользовательский сценарий:

1. Есть база магазинов.

Вкладка:
Магазины.

2. Каждый день загружается Excel с заявками.

Вкладка:
Заявки на день.

3. Система пытается сопоставить заявки с магазинами.

4. Пользователь нажимает:

К маршруту

5. Система автоматически выбирает магазины с заявками.

6. Строится маршрут.

Это основной рабочий сценарий.

ПРОБЛЕМА 1
МАССОВОЕ ДОБАВЛЕНИЕ МАГАЗИНОВ
-----------------------------

Тест:

В базе было 8 магазинов.

Загружено 92 новых точки.

Нажата кнопка:

Добавить все.

После завершения:

в базе оказалось 94 магазина.

То есть часть точек добавилась.

Но:

6 точек остались несопоставленными.

Требуется выяснить:

* почему именно эти точки не добавились;
* геокодинг;
* дубликаты;
* ошибки создания;
* ошибки rematch.

Нужен подробный отчёт пользователю.

---

ПРОБЛЕМА 2
НЕТ ПРОГРЕССА BULK CREATE
-------------------------

Во время массового добавления пользователь несколько минут ничего не понимает.

Нужен реальный прогресс.

Пример:

Создано 56 из 92.

Геокодировано 51 из 92.

Ошибок 5.
