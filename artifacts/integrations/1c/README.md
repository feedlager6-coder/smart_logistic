# SmartRoute.epf — Файл подключения 1С

## Как заменить заглушку настоящим EPF

1. Создайте `SmartRoute.epf` вручную в 1С:Конфигуратор (BSL-код находится в `artifacts/api-server/docs/integrations/1c/SmartRouteModule.bsl`)
2. Скопируйте готовый файл в эту директорию: `artifacts/integrations/1c/SmartRoute.epf`
3. Обновите `version.json`: установите `"status": "released"` и `"build_date"` 
4. Всё — больше никаких изменений в коде не требуется

## Что меняется для пользователя

- Кнопка «Скачать SmartRoute.epf» сразу начнёт отдавать настоящий файл
- В ZIP-архиве для специалиста появится рабочий EPF вместо заглушки
- Интеграция станет полностью рабочей

## Структура директории

```
artifacts/integrations/1c/
├── SmartRoute.epf    ← рабочий файл (заменить вручную)
├── version.json      ← метаданные версии
└── README.md         ← эта инструкция
```

## Технические детали

- EPF — бинарный контейнер платформы 1С, создаётся только в Конфигураторе
- Replit не может генерировать EPF автоматически
- BSL-исходник: `artifacts/api-server/docs/integrations/1c/SmartRouteModule.bsl`
- После установки EPF в 1С все настройки (URL, API-ключ) вводятся вручную или берутся из `Инструкция.txt` в архиве
