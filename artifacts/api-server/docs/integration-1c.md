# Интеграция SmartRoute ↔ 1С

Автоматически передавайте заказы из 1С:Предприятие в SmartRoute через HTTP-запросы.

## Подходы к интеграции

| Метод | Где работает | Сложность |
|---|---|---|
| HTTP-запрос из 1С (встроенный) | 1С 8.3+ | Низкая |
| Внешняя обработка (.epf) | 8.2+ | Средняя |
| COM-объект/ADODB | Старые версии | Высокая |

---

## Метод 1: HTTP-запрос из 1С 8.3 (рекомендуется)

### Шаг 1: Получите API-ключ SmartRoute
1. SmartRoute → Настройки → API-ключи → Создать ключ
2. Права: `orders:write`, `webhooks:receive`
3. Сохраните ключ

### Шаг 2: Обработка 1С (встраивается в модуль формы или регламентное задание)

```bsl
// ─────────────────────────────────────────────────────────────────────────────
// Процедура: ОтправитьЗаказыВSmartRoute
// Вызывать из регламентного задания или кнопки на форме
// ─────────────────────────────────────────────────────────────────────────────

Процедура ОтправитьЗаказыВSmartRoute() Экспорт

    СмартРоутURL = "https://ВАШ_ДОМЕН/api/v1/orders/batch";
    APIКлюч      = "sr_live_XXXX-XXXX";  // ← замените
    ДатаДоставки = Формат(ТекущаяДата(), "ДФ=yyyy-MM-dd");

    // ── 1. Получить заказы на сегодня ────────────────────────────────────
    Запрос = Новый Запрос;
    Запрос.Текст =
        "ВЫБРАТЬ
        |   З.Номер,
        |   З.Контрагент.Наименование КАК НаименованиеМагазина,
        |   З.АдресДоставки         КАК Адрес,
        |   З.ГородДоставки         КАК Город,
        |   З.КоличествоМест        КАК Количество,
        |   З.ВесКГ                 КАК ВесКГ,
        |   З.Комментарий           КАК Комментарий
        |ИЗ
        |   Документ.ЗаказКлиента КАК З
        |ГДЕ
        |   З.ДатаДоставки = &ДатаДоставки
        |   И З.Статус = ЗНАЧЕНИЕ(Перечисление.СтатусыЗаказов.ПодтверждёнДляДоставки)
        |   И НЕ З.ПометкаУдаления";

    Запрос.УстановитьПараметр("ДатаДоставки", НачалоДня(ТекущаяДата()));
    РезультатЗапроса = Запрос.Выполнить().Выгрузить();

    Если РезультатЗапроса.Количество() = 0 Тогда
        Сообщить("SmartRoute: нет заказов на " + ДатаДоставки);
        Возврат;
    КонецЕсли;

    // ── 2. Сформировать JSON ──────────────────────────────────────────────
    МассивЗаказов = Новый Массив;
    Для Каждого Строка Из РезультатЗапроса Цикл
        Заказ = Новый Структура;
        Заказ.Вставить("store_name",    СокрЛП(Строка.НаименованиеМагазина));
        Заказ.Вставить("address",       СокрЛП(Строка.Адрес));
        Заказ.Вставить("city",          ?(ПустаяСтрока(Строка.Город), "Махачкала", СокрЛП(Строка.Город)));
        Заказ.Вставить("delivery_date", ДатаДоставки);
        Заказ.Вставить("quantity",      ?(Строка.Количество = 0, 1, Строка.Количество));
        Заказ.Вставить("weight_kg",     Строка.ВесКГ);
        Заказ.Вставить("products",      СокрЛП(Строка.Комментарий));
        Заказ.Вставить("external_id",   СокрЛП(Строка.Номер));
        МассивЗаказов.Добавить(Заказ);
    КонецЦикла;

    ТелоЗапроса = Новый Структура;
    ТелоЗапроса.Вставить("orders",        МассивЗаказов);
    ТелоЗапроса.Вставить("delivery_date", ДатаДоставки);

    ЗаписьJSON = Новый ЗаписьJSON;
    НастройкиJSON = Новый НастройкиСериализацииJSON;
    НастройкиJSON.ВариантЗаписиДаты = ВариантЗаписиДатыJSON.ЛокальнаяДата;

    ГенераторJSON = Новый ГенераторJSON;
    ГенераторJSON.НастроитьВывод(ЗаписьJSON, НастройкиJSON);

    СтрокаТела = СериализаторXDTO.ЗаписатьJSON(ГенераторJSON, ТелоЗапроса);

    // ── 3. HTTP-запрос ────────────────────────────────────────────────────
    СоединениеHTTP = Новый HTTPСоединение(
        "ВАШ_ДОМЕН",  // ← только домен без https://
        443, , , , 30, Новый ЗащищённоеСоединениеOpenSSL
    );

    Заголовки = Новый Соответствие;
    Заголовки["Authorization"] = "Bearer " + APIКлюч;
    Заголовки["Content-Type"]  = "application/json; charset=utf-8";

    Запрос = Новый HTTPЗапрос("/api/v1/orders/batch", Заголовки);
    Запрос.УстановитьТелоИзСтроки(СтрокаТела, КодировкаТекста.UTF8, ИспользованиеByteOrderMark.НеИспользовать);

    Попытка
        Ответ = СоединениеHTTP.ОтправитьДляОбработки(Запрос);
    Исключение
        Сообщить("SmartRoute: ошибка соединения — " + ОписаниеОшибки());
        Возврат;
    КонецПопытки;

    // ── 4. Обработать ответ ───────────────────────────────────────────────
    КодОтвета = Ответ.КодСостояния;
    ТелоОтвета = Ответ.ПолучитьТелоКакСтроку();

    Если КодОтвета = 200 Или КодОтвета = 201 Тогда
        ЧтениеJSON = Новый ЧтениеJSON;
        ЧтениеJSON.УстановитьСтроку(ТелоОтвета);
        Данные = ПрочитатьJSON(ЧтениеJSON);

        ДанныеЗаказа = ?(Данные.Свойство("data", ДанныеОтвета), ДанныеОтвета, Данные);
        Сообщить(
            "SmartRoute ✅ Отправлено: " + ДанныеЗаказа["imported"]
            + " | Найдено магазинов: " + ДанныеЗаказа["matched"]
            + " | Не найдено: " + ДанныеЗаказа["unmatched"]
        );
    Иначе
        Сообщить("SmartRoute ❌ Ошибка " + КодОтвета + ": " + Лев(ТелоОтвета, 300));
    КонецЕсли;

КонецПроцедуры
```

## Метод 2: Регламентное задание

1. Откройте Конфигуратор → Метаданные → Регламентные задания → Добавить
2. Имя: `ОтправкаВSmartRoute`
3. Имя метода: `Обработки.ОтправкаВSmartRoute.Модуль.ОтправитьЗаказыВSmartRoute`
4. Расписание: ежедневно, 07:30

## Метод 3: Внешняя обработка (.epf)

Создайте `.epf`-файл "ОтправкаВSmartRoute" со следующей структурой:

```
├── Форма (основная)
│   ├── Поле: URL SmartRoute
│   ├── Поле: API-ключ
│   ├── Поле: Дата доставки
│   └── Кнопка: "Отправить в SmartRoute"
└── Модуль формы
    └── Процедура ОтправитьНажатие()
        └── Вызов: ОтправитьЗаказыВSmartRoute()
```

## Особенности HTTP в 1С

### SSL/TLS на Windows (типовая проблема)
Если сервер 1С на Windows и возникает ошибка SSL:
```bsl
// Установите сертификат или отключите проверку (только dev!)
НастройкиSSL = Новый ЗащищённоеСоединениеOpenSSL(,,, Ложь); // Ложь = не проверять сертификат
```

### Кодировка
SmartRoute ожидает UTF-8. В 1С при формировании тела:
```bsl
Запрос.УстановитьТелоИзСтроки(СтрокаТела, КодировкаТекста.UTF8, ИспользованиеByteOrderMark.НеИспользовать);
```

### Тестирование запроса
Для диагностики выводите тело ответа в консоль:
```bsl
Сообщить("Ответ: " + Ответ.ПолучитьТелоКакСтроку());
```

## Маппинг полей 1С → SmartRoute

| Поле SmartRoute | Поле 1С | Тип |
|---|---|---|
| `store_name` | Контрагент.Наименование | Строка |
| `address` | АдресДоставки | Строка |
| `city` | ГородДоставки | Строка |
| `delivery_date` | ДатаДоставки | Дата → `YYYY-MM-DD` |
| `quantity` | КоличествоМест | Число |
| `weight_kg` | ВесКГ | Число |
| `products` | Комментарий | Строка |
| `external_id` | Номер | Строка (для трассировки) |

## Troubleshooting

| Ошибка | Причина | Решение |
|---|---|---|
| Ошибка соединения | Брандмауэр блокирует HTTPS | Откройте порт 443 на сервере 1С |
| 401 Unauthorized | Неверный API-ключ | Проверьте значение `APIКлюч` |
| Не сериализуется JSON | Тип данных Дата | Конвертируйте в строку `Формат(Дата, "ДФ=yyyy-MM-dd")` |
| 422 Validation Error | Пустой `store_name` | Проверьте, что Контрагент заполнен |
| SSL Handshake Failed | Нет корневого сертификата | Установите Let's Encrypt bundle или используйте `Ложь` в `ЗащищённоеСоединениеOpenSSL` |
