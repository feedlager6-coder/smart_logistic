# Bitrix24 → SmartRoute
## Пошаговое руководство для пользователя

**Время настройки:** 10–15 минут  
**Требования:** доступ администратора в Bitrix24, Python 3.8+  
**Нужен программист?** Нет (только запустить скрипт)

---

## Шаг 1. Получите данные для подключения

### API-ключ SmartRoute
1. SmartRoute → **⚙️ Настройки** → **API-ключи** → **+ Создать ключ**
2. Название: `Bitrix24`
3. Права: **Заявки: запись**, **Webhook: приём заявок**
4. Скопируйте ключ

### Входящий Webhook Bitrix24
1. Войдите в Bitrix24 как администратор
2. В левом меню найдите **Разработчикам** → **Другое** → **Входящий webhook**

   > 📸 _[Скриншот: меню Разработчикам → Входящий webhook]_

   > Если пункта «Разработчикам» нет — попросите администратора включить его:  
   > Настройки → Приложения → Разработчикам

3. Нажмите **+ Добавить**
4. Дайте доступ к разделу **CRM**

   > 📸 _[Скриншот: выбор прав webhook]_

5. Скопируйте URL — он выглядит примерно так:  
   `https://ВАШ.bitrix24.ru/rest/1/abcdef123456/`

## Шаг 2. Настройте поля сделок Bitrix24

Скрипт читает данные из пользовательских полей сделок.  
По умолчанию используются поля с именами:

| Поле скрипта | Что содержит | Создать в Bitrix24 |
|---|---|---|
| `UF_CRM_DELIVERY_ADDRESS` | Адрес доставки | CRM → Сделки → Настройки → Пользовательские поля |
| `UF_CRM_DELIVERY_CITY` | Город | То же |
| `UF_CRM_DELIVERY_DATE` | Дата доставки | То же |
| `UF_CRM_QUANTITY` | Количество | То же |
| `UF_CRM_WEIGHT_KG` | Вес (кг) | То же |

**Как создать поля:**
1. Bitrix24 → **CRM** → **Сделки** → **⚙️ Настройки** → **Пользовательские поля**
2. Нажмите **+ Добавить поле**
3. Тип: Строка (для адреса/города), Дата (для даты), Число (для кол-ва и веса)
4. Задайте код точно как в таблице выше

> 📸 _[Скриншот: создание пользовательского поля]_

> Если у вас уже есть поля с другими именами — укажите их в настройках скрипта.

## Шаг 3. Создайте скрипт синхронизации

1. Установите Python: https://python.org/downloads  
   (При установке поставьте галочку «Add Python to PATH»)

2. В командной строке установите пакет:
   ```
   pip install requests
   ```

3. Запустите Мастер настройки SmartRoute:
   ```
   python3 setup_wizard.py
   ```

4. Выберите **«Bitrix24»** и введите URL входящего webhook

5. Мастер создаст файл `bitrix24_sync.py`

## Устранение проблем

### ❌ Bitrix24: ошибка (Invalid token)
- Пересоздайте входящий webhook в Bitrix24
- Обновите `BITRIX24_HOOK` в файле `bitrix24_sync.py`

### ❌ SmartRoute: неверный API-ключ
- Обновите `SMARTROUTE_KEY` в файле `bitrix24_sync.py`

### ❌ Найдено 0 сделок
- Проверьте, что поле `UF_CRM_DELIVERY_DATE` заполнено в сделках
- Или измените `FIELD_DATE` в скрипте на другое поле с датой (например `CLOSEDATE`)

### ❌ Поля adress/city пустые
- Заполните пользовательские поля в Bitrix24
- Или измените `FIELD_ADDRESS` в скрипте на поле, где хранится адрес

## Маппинг полей

| Поле SmartRoute | Поле Bitrix24 | Настройка |
|---|---|---|
| Название магазина | `COMPANY_TITLE` или `TITLE` | Автоматически |
| Адрес | `UF_CRM_DELIVERY_ADDRESS` | `FIELD_ADDRESS` в скрипте |
| Город | `UF_CRM_DELIVERY_CITY` | `FIELD_CITY` в скрипте |
| Дата доставки | `UF_CRM_DELIVERY_DATE` | `FIELD_DATE` в скрипте |
| Количество | `UF_CRM_QUANTITY` | `FIELD_QTY` в скрипте |
| Вес (кг) | `UF_CRM_WEIGHT_KG` | `FIELD_WEIGHT` в скрипте |

## Для программиста-интегратора

Альтернативные подходы (для продвинутых случаев):

**Исходящий webhook в реальном времени:**  
Bitrix24 → Разработчикам → Исходящий webhook → событие ONCRMDEALADD  
URL: нужен ваш сервер с endpoint-ом, который конвертирует данные и вызывает SmartRoute API.

**Bitrix24 Automation (бизнес-процессы):**  
Сделка → Роботы → Добавить действие → «HTTP-запрос»  
URL: `<BASE_URL>/api/v1/orders/batch`  
Метод: POST, Заголовок: Authorization: Bearer <ключ>

Документация SmartRoute API: `<BASE_URL>/api/v1/docs`
