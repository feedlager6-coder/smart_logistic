# SmartRoute — Руководство по интеграциям

## Быстрый старт — 3 простых шага

```
1. Создайте API-ключ: SmartRoute → Настройки → API-ключи → Создать ключ
2. Запустите мастер настройки: python3 setup_wizard.py
3. Следуйте инструкциям на экране
```

Мастер настройки задаст вам вопросы и создаст готовый к использованию скрипт  
для вашей системы — без программирования.

## Универсальный Webhook

Если вашей системы нет в списке — используйте прямой HTTP-запрос.  
Любая система с поддержкой HTTP-запросов (REST) может отправлять данные в SmartRoute.

**URL:**
```
POST https://ВАШ_ДОМЕН/api/v1/orders/batch
Authorization: Bearer sr_live_XXXX-XXXX
Content-Type: application/json
```

**Тело запроса:**
```json
{
  "orders": [
    {
      "store_name": "Магазин Центральный",
      "address": "ул. Пушкина, 10",
      "city": "Махачкала",
      "delivery_date": "2026-07-01",
      "quantity": 48,
      "weight_kg": 120.5,
      "products": "Молоко, Хлеб"
    }
  ]
}
```

**Ответ:**
```json
{
  "data": {
    "imported": 1,
    "matched": 1,
    "unmatched": 0
  }
}
```

> `matched` = магазин найден в базе SmartRoute  
> `unmatched` = магазин не найден — добавьте его вручную (SmartRoute → Магазины)

---

## Обязательные и необязательные поля

| Поле | Обязательное? | Описание | Пример |
|---|---|---|---|
| `store_name` | **Да** | Название магазина | `Магазин Центральный` |
| `delivery_date` | **Да** | Дата доставки (ГГГГ-ММ-ДД) | `2026-07-01` |
| `address` | Рекомендуется | Адрес доставки | `ул. Пушкина, 10` |
| `city` | Нет | Город | `Махачкала` |
| `quantity` | Нет | Количество (по умолчанию: 1) | `48` |
| `weight_kg` | Нет | Вес в кг | `120.5` |
| `products` | Нет | Список товаров / комментарий | `Молоко×12, Хлеб×24` |
| `external_id` | Нет | ID заказа в вашей системе | `ORD-2026-001` |
| `time_from` | Нет | Начало временного окна (ЧЧ:ММ) | `09:00` |
| `time_to` | Нет | Конец временного окна (ЧЧ:ММ) | `18:00` |

---

## Что происходит с данными

1. SmartRoute получает заявки через API
2. Ищет совпадение по названию магазина в базе (`matched`)
3. Несовпавшие — `unmatched` (нужно добавить магазин вручную)
4. Диспетчер открывает SmartRoute → Маршруты → выбирает дату → строит маршруты
5. Маршруты отправляются водителям через Яндекс.Навигатор / WhatsApp

## Управление API-ключами

| Действие | Где | Что делает |
|---|---|---|
| Создать ключ | SmartRoute → Настройки → API-ключи → + Создать | Генерирует ключ (показывается 1 раз) |
| Отозвать ключ | Кнопка «Отозвать» рядом с ключом | Деактивирует, сохраняет историю |
| Удалить ключ | Кнопка «Удалить» (для отозванных) | Удаляет навсегда |
| Обновить ключ | Кнопка «Обновить» | Новый ключ вместо старого |

## Проверка статуса интеграции

После настройки убедитесь, что данные приходят:

1. SmartRoute → **Заявки** (если есть этот раздел)
2. SmartRoute → **Маршруты** → выберите сегодняшнюю дату
3. Должны появиться магазины из вашей системы

Если магазины не появляются — проверьте:
- Статус отправки в скрипте (нет ли ошибок)
- Что `unmatched` равен 0 (все магазины найдены)
- Дату доставки в заявках (должна совпадать с датой в маршрутах)
