# МойСклад → SmartRoute
## Пошаговое руководство для пользователя

**Время настройки:** 10–15 минут  
**Требования:** Python 3.8+ на компьютере, API-токен МойСклад  
**Нужен программист?** Нет (но нужно запустить команду в терминале)

---

## Шаг 1. Получите данные для подключения

### API-ключ SmartRoute
1. SmartRoute → **⚙️ Настройки** → **API-ключи** → **+ Создать ключ**
2. Название: `МойСклад синхронизация`
3. Права: **Заявки: запись**, **Webhook: приём заявок**
4. Скопируйте ключ (показывается один раз!)

### API-токен МойСклад
1. Войдите в МойСклад
2. Нажмите на имя пользователя (правый верхний угол) → **Настройки**
3. Раздел **Безопасность** → **Токены** → **Создать токен**

   > 📸 _[Скриншот: раздел Токены в настройках МойСклад]_

4. Скопируйте токен

---

## Шаг 2. Установите Python (если не установлен)

**Windows:**
1. Откройте https://python.org/downloads
2. Скачайте Python 3.11 (кнопка «Download Python»)
3. При установке поставьте галочку ✅ **«Add Python to PATH»**
4. Установите

**Mac:**  
Python обычно уже установлен. Проверьте: откройте Terminal и введите `python3 --version`

**Linux:**  
```bash
sudo apt install python3 python3-pip
```

---

## Шаг 3. Создайте скрипт синхронизации

1. Откройте **Командную строку** (Windows: Win+R → `cmd`) или **Terminal** (Mac/Linux)

2. Установите необходимый пакет:
   ```
   pip install requests
   ```

3. Запустите Мастер настройки SmartRoute:
   ```
   python3 setup_wizard.py
   ```

4. Выберите **«МойСклад»** и введите:
   - Адрес SmartRoute сервера
   - API-ключ SmartRoute  
   - API-токен МойСклад

5. Мастер создаст файл `moysklad_sync.py` с вашими настройками

---

## Шаг 4. Проверьте соединение

В командной строке/терминале выполните:

```bash
python3 moysklad_sync.py --test
```

Вы должны увидеть:
```
🔌 Проверка соединений...

  ✅ SmartRoute: подключено (ключ: МойСклад синхронизация)
  ✅ МойСклад: подключено (пользователь: Иван Иванов)

  ✅ Оба соединения работают. Можно запускать синхронизацию.
```

**Если видите ошибки** — см. раздел [Устранение проблем](#устранение-проблем).

## Шаг 5. Запустите синхронизацию

### Разовая синхронизация (сегодня):

```bash
python3 moysklad_sync.py --date 2026-07-15
```

## Шаг 6. Настройте автоматический запуск

### Windows (Планировщик задач):
1. Откройте «Планировщик задач» (поиск в меню Пуск)
2. Нажмите «Создать простую задачу»
3. Имя: `SmartRoute — МойСклад`
4. Триггер: «Ежедневно» в **7:30**
5. Действие: «Запустить программу»
6. Программа: `python3`
7. Аргументы: `C:\путь\до\moysklad_sync.py`

### Mac/Linux (cron):
В терминале выполните `crontab -e` и добавьте строку:
```
30 7 * * * python3 /полный/путь/до/moysklad_sync.py >> ~/smartroute_sync.log 2>&1
```

> Замените `/полный/путь/до/` на реальный путь к файлу скрипта.  
> Узнать полный путь: в терминале введите `pwd` в папке со скриптом.

## Устранение проблем

### ❌ SmartRoute: неверный API-ключ
- Откройте файл `moysklad_sync.py` любым текстовым редактором
- Найдите строку `SMARTROUTE_KEY = "..."` и обновите ключ
- Убедитесь, что ключ активен в SmartRoute → Настройки → API-ключи

### ❌ МойСклад: неверный токен
- Зайдите в МойСклад → Настройки → Безопасность → Токены
- Создайте новый токен
- Обновите строку `MOYSKLAD_TOKEN = "..."` в файле `moysklad_sync.py`

### ❌ МойСклад: ошибка API 401
- Токен мог истечь — создайте новый
- Убедитесь, что у вас есть права на чтение заказов в МойСклад

### ❌ Найдено 0 заказов
- В МойСклад нет заказов на указанную дату
- Проверьте фильтр по полю даты (`DATE_FIELD` в скрипте)
- По умолчанию фильтрует по `deliveryPlannedMoment` — плановой дате доставки

### ❌ Не найдено магазинов: N
- Добавьте магазины в SmartRoute → Магазины → Добавить магазин
- Или импортируйте из Excel: Магазины → Импорт из Excel

## Маппинг полей МойСклад → SmartRoute

| Поле SmartRoute | Поле МойСклад | Где взять |
|---|---|---|
| Название магазина | `agent.name` | Контрагент заказа |
| Адрес | `shippingAddress.street` | Адрес доставки заказа |
| Город | `shippingAddress.city` | Город из адреса доставки |
| Дата доставки | `deliveryPlannedMoment` | Дата отгрузки |
| Количество | Сумма `positions.quantity` | Позиции заказа |
| Вес (кг) | `positions.assortment.weight × quantity` | Из карточки товара |
| Внешний ID | `id` | UUID заказа |

## Для программиста-интегратора

Скрипт `moysklad_sync.py` содержит:
- `test_connections()` — проверка обоих соединений
- `get_ms_orders(date)` — получение заказов из МойСклад API
- `convert_order(order, date)` — конвертация в формат SmartRoute
- `sync(date)` — основной процесс синхронизации

Настройки в начале файла:
- `STAGE_FILTER` — фильтр по этапу сделки (например `"WON"`)
- `DATE_FIELD` — поле МойСклад для фильтрации по дате

API SmartRoute: `POST /api/v1/orders/batch`  
Документация: `<BASE_URL>/api/v1/docs`
