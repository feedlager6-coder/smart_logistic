# SmartRoute ↔ 1С:Предприятие
## Руководство по интеграции (версия 3.0)

**Время подключения:** 20–40 минут  
**Требования:** 1С:Предприятие 8.3+, интернет с сервера 1С (порт 443)  
**Нужен программист 1С?** Да — для первичной настройки. Затем всё работает автоматически.

---

## Как работает интеграция

```
Каждое утро в 07:30 (или вручную)
  1С отправляет заказы → SmartRoute
  SmartRoute сопоставляет точки доставки
  Диспетчер нажимает «Построить маршрут»
  Водители получают маршруты в Яндекс Навигаторе
```

---

## ДЛЯ РУКОВОДИТЕЛЯ

Вы передаёте специалисту по 1С:
1. Архив `SmartRoute_Setup.zip` (скачайте в SmartRoute → Интеграции → 1С)
2. Этот документ

Что специалист сделает:
- Откроет файл `SmartRoute.epf` в 1С:Предприятие
- Введёт URL и API-ключ из архива
- Нажмёт «Проверить соединение» (ожидается ✅)
- Настроит автоматический запуск каждое утро

После настройки — ничего делать не нужно. Заказы передаются автоматически.

## ДЛЯ СПЕЦИАЛИСТА ПО 1С

### Что находится в архиве SmartRoute_Setup.zip

| Файл | Назначение |
|---|---|
| `SmartRoute.epf` | Готовый файл обработки — открыть в 1С:Предприятие |
| `SmartRoute.bsl` | Исходный код (если EPF не открывается — используйте этот) |
| `Инструкция.txt` | Краткая инструкция + данные подключения |

URL и API-ключ **уже встроены** в файлы. Менять ничего не нужно — только проверить соединение.

---

### Вариант А — Открыть готовый EPF (рекомендуется)

1. Запустите **1С:Предприятие** (режим Предприятие, НЕ Конфигуратор)
2. Файл → Открыть → найдите `SmartRoute.epf`
3. Нажмите **«Проверить соединение»**
4. Ожидаемый результат: `✅ Соединение установлено! Магазинов в базе SmartRoute: N`
5. Настройте вкладку «Настройки»: укажите реквизиты вашего документа заказа
6. Настройте регламентное задание (раздел ниже)

---

### Вариант Б — Сборка из BSL-кода (если EPF не открывается)

1. Откройте 1С в режиме **Конфигуратора**
2. Файл → Новый → Внешняя обработка → Имя: `SmartRoute`
3. Формы → Добавить → Произвольная форма → ОК
4. Разместите на форме элементы:
   - Поле типа «Дата»: имя `ПолеДатаДоставки`
   - Кнопка «Проверить соединение» → Команда: `СмартРоутПроверить`
   - Кнопка «Отправить заявки» → Команда: `СмартРоутОтправить`
5. Перейдите на вкладку **«Модуль»**
6. Откройте `SmartRoute.bsl` — скопируйте всё содержимое и вставьте в модуль формы
7. В начале модуля найдите строки и заполните:
   ```
   URLSmartRoute = "https://ВАШ-ДОМЕН";   // ← адрес из Инструкция.txt
   APIКлюч       = "sr_live_XXXX";         // ← ключ из Инструкция.txt
   ```
8. Файл → Сохранить как → тип «Внешняя обработка (*.epf)»
9. Откройте сохранённый EPF в режиме Предприятия → Проверить соединение

### Настройка реквизитов документа

В разделе «Настройки» EPF укажите названия реквизитов вашей конфигурации.

| Параметр | Что указать | Пример |
|---|---|---|
| Документ заказа | Имя документа в конфигурации | `ЗаказКлиента`, `ЗаказПокупателя` |
| Реквизит даты | Имя реквизита с датой доставки | `ДатаДоставки`, `ДатаОтгрузки` |
| Реквизит адреса | Имя реквизита с адресом доставки | `АдресДоставки`, `АдресПолучателя` |
| Реквизит количества | Имя реквизита с количеством мест | `КоличествоМест`, `Количество` |
| Реквизит веса | Имя реквизита с весом (кг) | `ВесКГ`, `Вес` |

> **Как найти имя реквизита:** откройте документ в конфигураторе → вкладка «Реквизиты» → столбец «Имя» (не «Синоним»).

---

### Ключевое поле — Код контрагента

BSL-модуль автоматически передаёт `Контрагент.Код` в поле `counterparty_code`.  
**Это самое важное поле для точного совпадения магазинов** — SmartRoute использует его как внешний ID.

В первый раз магазины создаются автоматически и привязываются к коду контрагента.  
При следующих синхронизациях — совпадение мгновенное, без ошибок.

---

### Настройка регламентного задания

Откройте **Сервис → Регламентные задания** (или **Администрирование → Обслуживание**):

| Поле | Значение |
|---|---|
| Наименование | SmartRoute — ежедневная синхронизация |
| Использование | ✅ Да |
| Ключ | SmartRoute |
| Имя метода | Путь к `ОтправитьЗаявки` в модуле обработки |
| Расписание | Ежедневно в **07:30** |

После сохранения регламентное задание будет запускаться автоматически каждое утро.

---

### Ручная отправка (по кнопке)

Если нужно передать заказы вне расписания:
1. Откройте SmartRoute.epf в 1С:Предприятие
2. Выберите дату
3. Нажмите «Отправить заявки»

Результат отображается на форме и записывается в журнал регистрации 1С.

## ДИАГНОСТИКА

### ❌ Не удалось подключиться к серверу

- Проверьте, что сервер 1С имеет выход в интернет через порт 443
- Проверьте брандмауэр — он должен разрешить исходящие HTTPS-запросы
- Убедитесь, что адрес SmartRoute правильный (без лишнего `/` в конце)
- На Windows Server 2012/2016: SSL-ошибки решены в BSL 3.0 (используется `Ложь` для верификации)

### ❌ Неверный API-ключ

- Ключ показывается **только один раз** при генерации архива
- Если ключ утерян: откройте SmartRoute → Интеграции → 1С → «Сгенерировать новый пакет»

### ❌ Ошибка запроса к базе данных

- Неверно указаны реквизиты в разделе «Настройки»
- Проверьте имена через Конфигуратор → Документ → Реквизиты → столбец «Имя»

### ⚠️ Новые точки без координат

После первой синхронизации SmartRoute автоматически создаёт неизвестные точки доставки.  
Диспетчер увидит жёлтый алерт в SmartRoute → Интеграции: **«N магазинов без координат»**.  
Перейдите в Магазины → геокодируйте вручную или через Яндекс-ссылку.

## ПЕРЕДАВАЕМЫЕ ДАННЫЕ

| Поле | Источник в 1С | Назначение |
|---|---|---|
| store_name | Контрагент.Наименование | Название точки доставки |
| counterparty_code | **Контрагент.Код** | Точное совпадение (основной ключ!) |
| address | РеквизитАдресаДоставки | Адрес для геокодирования |
| city | ГородПоУмолчанию | Уточнение города |
| phone | Контрагент.Телефон | Контакт получателя |
| delivery_date | дата из поля формы | Дата доставки |
| quantity | РеквизитКоличества | Количество мест |
| weight_kg | РеквизитВеса | Вес груза (кг) |
| products | Комментарий документа | Состав заказа |
| order_number | Номер документа | Номер для отслеживания |
