# 1С:Предприятие → SmartRoute
## Пошаговое руководство

**Время настройки:** 45–60 минут (нужен программист 1С)  
**Требования:** 1С:Предприятие 8.3+, доступ к конфигуратору  
**Нужен программист?** Да — но только для установки (скопировать готовый код)

---

## Для руководителя: что нужно объяснить программисту

Передайте программисту:
1. Этот документ
2. Файл `SmartRouteModule.bsl` (создаётся мастером настройки)
3. API-ключ SmartRoute (создайте заранее в SmartRoute → Настройки → API-ключи)

**Что нужно сделать программисту:**
- Создать внешнюю обработку в конфигурации
- Вставить готовый код (файл `.bsl`)
- Настроить реквизиты документа (название/адрес поля)
- Настроить регламентное задание на 07:30

**Всё остальное уже готово** — соединение, обработка ошибок, форматирование данных.

## Для программиста 1С: пошаговая установка

### Шаг 1. Получите готовый код

Запустите мастер настройки SmartRoute:
```bash
python3 setup_wizard.py
```

Выберите **«1С:Предприятие»** и введите:
- Адрес сервера SmartRoute
- API-ключ
- Имя документа заказа в 1С (например: `ЗаказКлиента`)
- Реквизит с датой доставки
- Реквизит с адресом доставки

Мастер создаст файл `SmartRouteModule.bsl` с вашими настройками.

---

### Шаг 2. Создайте внешнюю обработку

1. Откройте **Конфигуратор** (режим конфигуратора, не предприятия)

2. Меню **Файл → Новый → Внешняя обработка**

   > 📸 _[Скриншот: меню Файл → Новый → Внешняя обработка]_

3. Имя: `SmartRoute`
4. Синоним: `SmartRoute — отправка заявок`

---

### Шаг 3. Создайте форму

1. В дереве обработки: **Формы → Добавить**
2. Тип: **Обычная форма**
3. На форме разместите:

| Элемент | Тип | Имя | Подпись |
|---|---|---|---|
| Поле ввода | Дата | ПолеДатаДоставки | Дата доставки |
| Кнопка | — | КнопкаПроверить | 🔌 Проверить соединение |
| Кнопка | — | КнопкаОтправить | 📦 Отправить заявки |

   > 📸 _[Скриншот: форма с кнопками в дизайнере]_

4. Для кнопки «Проверить» задайте команду: `СмартРоутПроверить`
5. Для кнопки «Отправить» задайте команду: `СмартРоутОтправить`

---

### Шаг 4. Вставьте модуль

1. Откройте **Модуль формы** (вкладка «Модуль»)
2. Нажмите **Ctrl+A**, затем **Delete**
3. Откройте файл `SmartRouteModule.bsl` в текстовом редакторе
4. Скопируйте весь текст (**Ctrl+A → Ctrl+C**)
5. Вставьте в модуль формы (**Ctrl+V**)

   > 📸 _[Скриншот: модуль формы с кодом]_

6. Проверьте и при необходимости исправьте константы в начале модуля:
   ```bsl
   URLSmartRoute    = "https://ВАШ_ДОМЕН";
   APIКлюч          = "sr_live_XXXX-XXXX";
   ГородПоУмолчанию = "Махачкала";
   ```

---

### Шаг 5. Настройте запрос к данным 1С

В функции `ОтправитьЗаявкиНаСервере` найдите запрос и адаптируйте:

```bsl
// Замените имена реквизитов на реальные из вашей конфигурации:
Запрос.Текст =
    "ВЫБРАТЬ
    |   З.Контрагент.Наименование КАК Магазин,
    |   З.АдресДоставки           КАК Адрес,     ← ваш реквизит адреса
    |   З.КоличествоМест          КАК Количество,
    |   З.ВесКГ                   КАК ВесКГ,
    |   З.Комментарий             КАК Комментарий,
    |   З.Номер                   КАК Номер
    |ИЗ
    |   Документ.ЗаказКлиента КАК З             ← ваш документ
    |ГДЕ
    |   З.ДатаДоставки = &ДатаДоставки          ← ваш реквизит даты
    |   И НЕ З.ПометкаУдаления
    |   И З.Проведён";
```

---

### Шаг 6. Проверьте соединение

1. Сохраните обработку (Ctrl+S)
2. Запустите 1С в режиме **Предприятия**
3. Файл → Открыть → выберите обработку `SmartRoute.epf`
4. Нажмите кнопку **🔌 Проверить соединение**

Ожидаемый результат:
```
✅ Соединение установлено!
Ключ: SmartRoute 1С
Магазинов в базе SmartRoute: 42
```

**Если ошибка «SSL Handshake Failed»** — добавьте сертификат:
```bsl
// В функции _ПолучитьСоединение() замените:
СоединениеSSL = Новый ЗащищённоеСоединениеOpenSSL(,,, Ложь);
// Параметр Ложь = не проверять SSL (только для тестирования)
```

---

### Шаг 7. Настройте регламентное задание

1. Конфигуратор → **Метаданные** → **Регламентные задания** → **Добавить**

   > 📸 _[Скриншот: регламентные задания в конфигураторе]_

2. Имя: `ОтправкаВSmartRoute`
3. Синоним: `SmartRoute — ежедневная отправка`
4. Имя метода: выберите метод `ОтправитьЗаявки` из обработки

   ```
   ВнешниеОбработки.SmartRoute.ОтправитьЗаявки
   ```
   > Или создайте общий модуль `СмартРоутИнтеграция` с экспортируемой процедурой

5. Расписание: ежедневно в **07:30**

## Устранение проблем

### ❌ «Ошибка соединения» / «Не удалось подключиться»
- Сервер 1С не имеет доступа в интернет
- Решение: попросите системного администратора открыть порт 443 на сервере
- Или: настройте HTTPS через корпоративный прокси

### ❌ «Неверный API-ключ»
- Обновите `APIКлюч` в коде
- Убедитесь, что ключ активен: SmartRoute → Настройки → API-ключи

### ❌ «SSL Handshake Failed» (Windows Server)
- Установите корневой сертификат Let's Encrypt:
  `certutil -addstore Root lets-encrypt-r3.pem`
- Или временно используйте `Новый ЗащищённоеСоединениеOpenSSL(,,, Ложь)`

### ❌ «Запрос вернул 0 строк»
- Проверьте имя документа и реквизита даты в запросе
- Убедитесь, что документы проведены
- Добавьте отладочный вывод: `Сообщить(РезультатЗапроса.Количество());`

### ❌ «Ошибка в данных» (422 от SmartRoute)
- Убедитесь, что поле `store_name` (магазин) не пустое
- Проверьте формат даты: должен быть `ГГГГ-ММ-ДД`

## Частые вопросы

**Q: Можно ли отправлять заявки из разных документов (заказы + накладные)?**  
A: Да — создайте два запроса в функции `ОтправитьЗаявкиНаСервере` и объедините массивы.

**Q: Как добавить свой статус для фильтрации?**  
A: В запросе добавьте условие: `И З.Статус = ЗНАЧЕНИЕ(Перечисление.СтатусыЗаказов.ГотовКДоставке)`

**Q: Нужно ли соединение с интернетом на рабочей станции?**  
A: Нет — только на сервере 1С (или терминальном сервере, если работаете через него).

**Q: Что делать, если сервер 1С за корпоративным прокси?**  
A: Добавьте настройки прокси в `HTTPСоединение`:
```bsl
Прокси = Новый ИнтернетПрокси("http", "192.168.1.100", 8080);
Возврат Новый HTTPСоединение(Хост, Порт, Прокси, , , 30, СоединениеSSL);
```
