# Google Таблицы → SmartRoute
## Пошаговое руководство для пользователя

**Время настройки:** 5–10 минут  
**Требования:** аккаунт Google, Google Таблица с данными о заказах  
**Нужен программист?** Нет

---

## Шаг 1. Получите API-ключ SmartRoute

1. Откройте SmartRoute в браузере
2. В левом меню нажмите **⚙️ Настройки**
3. Выберите вкладку **API-ключи**
4. Нажмите кнопку **+ Создать ключ**

   > 📸 _[Скриншот: экран создания API-ключа]_

5. В поле «Название» введите: `Google Таблицы`
6. В правах отметьте галочки: **Заявки: запись** и **Webhook: приём заявок**
7. Нажмите **Создать**

   > ⚠️ **Важно:** Ключ показывается только один раз. Скопируйте его сразу.

8. Скопируйте ключ — он выглядит примерно так:  
   `sr_live_a1b2c3d4-e5f6-7890-abcd-ef1234567890`

---

## Шаг 2. Подготовьте таблицу

Ваша Google Таблица должна иметь строку с заголовками в первой строке.

**Минимальная структура таблицы:**

| Магазин | Адрес | Дата доставки | Количество |
|---|---|---|---|
| Магазин Центральный | ул. Пушкина, 10 | 01.07.2026 | 48 |
| Магазин Северный | пр. Ленина, 55 | 01.07.2026 | 32 |

**Поддерживаемые названия колонок:**

| Что это | Варианты названий колонок |
|---|---|
| Название магазина | Магазин, Store, Название, Наименование |
| Адрес | Адрес, Address |
| Город | Город, City |
| Дата доставки | Дата, Date, Дата доставки |
| Количество | Количество, Кол-во, Qty, Quantity |
| Вес (кг) | Вес, Weight, КГ |
| Комментарий | Комментарий, Примечание, Товары, Products |

> Скрипт автоматически находит колонки по заголовкам. Порядок колонок не важен.

---

## Шаг 3. Установите скрипт

1. Откройте вашу Google Таблицу

2. В верхнем меню выберите:  
   **Расширения → Apps Script**

   > 📸 _[Скриншот: меню Расширения → Apps Script]_

3. Откроется редактор кода. Нажмите **Ctrl+A** (выделить всё), затем **Delete** (удалить)

4. Запустите Мастер настройки SmartRoute:
   ```
   python3 setup_wizard.py
   ```
   Выберите **«Google Таблицы»** и следуйте инструкциям.  
   Мастер создаст файл `SmartRoute_GoogleSheets.gs`

5. Откройте созданный файл любым текстовым редактором (Блокнот, TextEdit)

6. Выделите весь текст (**Ctrl+A**), скопируйте (**Ctrl+C**)

7. Вернитесь в Apps Script, вставьте текст (**Ctrl+V**)

   > 📸 _[Скриншот: код вставлен в Apps Script]_

8. Нажмите **💾 Сохранить** (или Ctrl+S)

---

## Шаг 4. Проверьте соединение

1. Обновите страницу Google Таблицы (F5)

2. Через несколько секунд в меню появится пункт **SmartRoute**

   > 📸 _[Скриншот: меню SmartRoute в таблице]_

3. Нажмите **SmartRoute → 🔌 Проверить соединение**

4. Google попросит разрешение — нажмите **Разрешить**

   > 📸 _[Скриншот: диалог разрешений Google]_

5. Должно появиться сообщение:
   ```
   ✅ Соединение работает!
   Ключ: Google Таблицы
   Магазинов в базе: 42
   ```

**Если видите ошибку** — см. раздел [Устранение проблем](#устранение-проблем) ниже.

---

## Шаг 5. Отправьте заявки

1. Нажмите **SmartRoute → 📦 Отправить заявки**

2. Появится подтверждение: «Готово к отправке: N заявок. Отправить?»

3. Нажмите **Да**

4. Вы увидите результат:
   ```
   ✅ Заявки отправлены успешно!
   Загружено заявок: 12
   Найдено магазинов: 10
   ⚠️ Не найдено магазинов: 2
   ```

> Если `unmatched > 0` — эти магазины нужно добавить в SmartRoute вручную  
> (SmartRoute → Магазины → Добавить магазин)

---

## Шаг 6. Настройте авто-отправку (необязательно)

Чтобы заявки отправлялись каждое утро автоматически:

1. Нажмите **SmartRoute → 📅 Настроить авто-отправку**
2. Готово — каждый день в 8:00 данные из таблицы будут отправляться в SmartRoute

Для отключения: **SmartRoute → 🗑 Отключить авто-отправку**

## Устранение проблем

### ❌ «Меню SmartRoute не появляется»
- Обновите страницу (Ctrl+F5 или Shift+F5)
- Подождите 10–15 секунд после обновления
- Проверьте, что код сохранён в Apps Script (Ctrl+S)

### ❌ «Неверный API-ключ»
1. Откройте SmartRoute → Настройки → API-ключи
2. Убедитесь, что ключ активен (нет надписи «Отозван»)
3. Откройте Apps Script, найдите строку `SMARTROUTE_KEY = "..."` и замените ключ
4. Сохраните (Ctrl+S) и попробуйте снова

### ❌ «Лист не найден»
- В коде задана переменная `SHEET_NAME = "Заявки"` — убедитесь, что ваш лист называется именно так
- Дважды щёлкните на вкладке листа, переименуйте его в `Заявки`
- Или в Apps Script найдите `SHEET_NAME` и поменяйте на реальное название листа

### ❌ «Нет данных для отправки»
- Убедитесь, что данные начинаются со строки 2 (строка 1 — заголовки)
- Проверьте, что в колонке «Магазин» есть значения
- Убедитесь, что выбран правильный лист

### ❌ «Не найдено магазинов: N»
- Эти магазины отсутствуют в базе SmartRoute
- Добавьте их: SmartRoute → Магазины → Добавить магазин
- Или импортируйте списком: Магазины → Импорт из Excel

## Сопоставление полей

| Поле SmartRoute | Колонка в таблице | Обязательное? |
|---|---|---|
| Название магазина | Магазин / Store | **Да** |
| Адрес | Адрес / Address | Рекомендуется |
| Город | Город / City | Нет (по умолчанию: Махачкала) |
| Дата доставки | Дата / Date | Нет (по умолчанию: сегодня) |
| Количество | Количество / Qty | Нет (по умолчанию: 1) |
| Вес (кг) | Вес / Weight | Нет |
| Товары/комментарий | Комментарий / Products | Нет |

## Для программиста-интегратора

Если нужна нестандартная настройка (другая структура таблицы, сложная логика):

- Файл скрипта: `SmartRoute_GoogleSheets.gs` (создаётся мастером)
- Основные функции: `sendOrdersToSmartRoute()`, `checkConnection()`
- API endpoint: `POST /api/v1/orders/batch` (Bearer auth)
- Документация API: `<BASE_URL>/api/v1/docs`
- Найти нужную колонку: функция `findCol(headers, variants)` — добавьте свои варианты названий
